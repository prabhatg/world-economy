Lend this tab to simulate one possible history

Your browser runs one world: Southwest Asia from 12,000 to 3,000 BCE, as people forage, settle and start to farm. A second computer runs the same world. When the two match exactly, yours helps test which histories fit the archaeological record.

While running, it uses one processor core. About 25 MB to download the first time.

How this works

The page runs the same simulation engine as every other computer in the project, compiled to WebAssembly, so the same world gives the same result to the last bit on any device. It runs in your browser's sandbox and cannot read your files.

It downloads the world's land, climate and settings from the project's server, checks each file against its fingerprint, and sends back the record of the world it simulated. Nothing about you is sent: this browser is known only by a random name, .

Close the tab or press Stop at any time. A world left unfinished is given to another computer.
